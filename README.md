# iPad Termux (No PC, No Sideloading)

A **Termux-like Linux terminal environment on iPad** using **GitHub Codespaces**.
Runs fully in the browser, works on latest iPadOS, and requires **no computer**.

---

## What This Is
This project gives you:
- A real Linux shell (bash)
- `apt`, `python`, `pip`, `git`, `node`
- Persistent storage
- Works on iPadOS 26+
- Launches like an app from Home Screen

This is **not** an emulator and **not** a fake terminal.

---

## Requirements
- iPad (any model)
- iPadOS 26+
- GitHub account
- Internet connection

No PC. No jailbreak. No sideloading.

---

## How to Start the Terminal

1. Open this repository on GitHub
2. Tap **Code**
3. Go to **Codespaces**
4. Tap **Create codespace on main**
5. Wait for Linux to start (~1 min)

You now have a real Linux environment.
